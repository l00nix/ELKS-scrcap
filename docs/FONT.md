# Fallback font

The 256-glyph 8×8 fallback is taken unchanged from the GPL-2.0 ELKS source
`elks/arch/i86/drivers/char/console-font-8x8-swan.S` at commit
`df2a61c5d72415ff4825aab33be427de9306c230`.
Source: https://github.com/ghaerr/elks/blob/df2a61c5d72415ff4825aab33be427de9306c230/elks/arch/i86/drivers/char/console-font-8x8-swan.S

This fallback is not a claim to reproduce every adapter font. The program
reports when it substitutes/scales a font. See COPYING for GPL terms.
